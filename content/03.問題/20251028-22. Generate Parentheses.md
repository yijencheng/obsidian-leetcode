https://leetcode.com/problems/generate-parentheses/description/
Description: Given `n` pairs of parentheses, write a function to _generate all combinations of ==well-formed parentheses==.

Example 1:
> Input: n = 3
> Output: ["((()))","(()())","(())()","()(())","()()()"]

### High-level Solution
Generate a tree as below:
   '('
   /  \
  '(' ')' 
  ...

**Questions**
* how to make sure every path is ==valid== ?
	* for 'invalid' path: ')' has more than '(' in any give time

**Naive Idea**
```python
def generateParenthesis(self, n: int) -> List[str]:
	open = []
	close = []
	ans = []
	def dfs(cur, open, close):
		if len(open) == n and len(close) == n:
			ans.append(cur)
			return
		# invalid 
		if len(close) > len(open):
			return
		
		# valid
		dfs(cur+ '(', open + ['('], close)
		dfs(cur+ ')', open , close + [')'])
		return
	return dfs('', [], [])
```

但你可能接著會發現... 這個open/close 似乎沒必要，因為存的都是同樣的東西。因此優化如下：

```python
def generateParenthesis(self, n: int) -> List[str]:
        open = 0
        close = 0
        ans = []
        def dfs(cur, open, close):
            if open == n and close == n:
                ans.append(cur)
                return
            # invalid 
            if close > open or open >n or close >n: # important edge case
                return
            
            # valid
            dfs(cur+ '(', open + 1, close)
            dfs(cur+ ')', open , close +1)
            return
        dfs('', 0, 0)
        return ans
```
